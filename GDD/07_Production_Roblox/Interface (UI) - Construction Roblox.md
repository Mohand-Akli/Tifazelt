# 🖥️ Interface (UI) — Construction Roblox

> Mise en œuvre dans Studio de la [[16. Direction Artistique des Menus]]. Plan des écrans : [[Liste des Menus et Écrans]]. Index : [[00. Production Roblox]].

Tout le code de l'interface est dans `ReplicatedStorage.UI` (écrans dans `UI.Ecrans`) et démarre par `StarterPlayerScripts.UI_Client`. Le détail est rangé une note par phase dans le dossier `Interface (UI) - Construction Roblox/`.

| Phase | Contenu |
| :--- | :--- |
| [[Interface (UI) - Phase 0 - Fondations]] | `Theme`, `Anim`, `Kit`, `MenuManager`, données de test ; animations communes ; écran ÉQUIPE prototype. |
| [[Interface (UI) - Phase 1 - Exploration]] | HUD, bandeau de zone, dialogues, invites d'action, onglets et listes. |
| [[Interface (UI) - Phase 2 - Menu principal et sous-menus]] | Menu, Équipe, Fiche, Sac, Livre de compétences, Tifalistre, Carte de dresseur, Quêtes, Carte, Paramètres. |
| [[Interface (UI) - Phase 3 - Combat]] | Règles, moteur, scène, ouverture des combats de dresseur, fenêtres ; formules provisoires. |
| [[Interface (UI) - Phase 4 - Bâtiments et services]] | Infirmerie, Magasin (et magasin de vélos), Restaurant, Guilde, Investissement, Pâturage, Sanctuaire. |
| [[Interface (UI) - Phase 5 - Début de partie]] | Écran titre, création du dresseur, classes, chargement, starter. |
| [[Interface (UI) - Phase 6 - En ligne]] | Joueurs à proximité, combat en ligne, échange, carte d'un autre joueur, boss de raid. |
| [[Interface (UI) - Phase 7 - Mini-jeux et énigmes]] | Pêche, plongée, énigmes. |
| [[Interface (UI) - Pièges Roblox]] | Pièges rencontrés dans Studio, à respecter pour chaque nouvel écran. |
